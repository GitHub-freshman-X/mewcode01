# MewCode 应用日志 Spec

## 背景

当前 MewCode 仅将少量启动和运行错误写入标准错误，没有持久化的运行记录。MCP Server 的连接、初始化、工具发现、注册和调用也缺少成功事件，无法判断 `filesystem__...` 等远端工具是否已经注册或在哪个阶段失败。

本章提供可复用的应用日志模块，并首先完整接入 MCP 模块。后续章节应复用该模块，为 Agent、Provider、权限和内置工具逐步补充全流程可观测性。

## 目标

- 在项目根目录的 `logs/` 下持久化本次 MewCode 运行的日志。
- 提供稳定、结构化且不泄露敏感信息的日志接口。
- 记录 MCP 的配置、连接、初始化、发现、注册、调用和关闭全生命周期，并能明确判断远端工具是否注册成功。
- 让后续模块能以相同接口补充日志，而不依赖 MCP 内部实现。

## 功能需求

- **F1 日志文件创建**：MewCode 在已确定项目根目录后，创建 `logs/`（若不存在）并为当前进程创建独立日志文件。文件名应包含可区分本次运行的时间和进程信息，避免并发启动互相覆盖。
- **F2 结构化事件**：每条日志独立成行，包含时间、级别、调用位置、可读消息和可选字段。字段结构在同一版本内保持稳定，支持按来源文件、Server 名和工具名检索。
- **F3 可复用日志模块**：日志模块提供线程安全的记录接口，调用方无需了解文件创建、序列化或同步细节。日志初始化失败不得阻止 MewCode 启动，且应继续通过标准错误报告该失败。
- **F4 MCP 启动与注册日志**：对每个 MCP Server 记录配置展开、传输创建和连接、初始化、初始化通知、工具发现、工具注册、冲突和关闭事件。成功注册时必须记录 Server 名、远端工具名和最终注册名；失败时必须记录 Server 名和失败阶段。
- **F5 MCP 调用日志**：远端工具执行时记录调用开始、成功、MCP 工具错误、JSON-RPC/传输错误和完成状态；日志可关联 Server 名和最终工具名。
- **F6 敏感信息保护**：日志不得写入 API Key、Authorization 值、HTTP header 值、环境变量展开值、完整子进程环境、完整工具参数、文件内容或 MCP 工具结果内容。错误文本在写入前必须避免包含这些值。
- **F7 后续扩展约定**：日志模块和事件字段约定应可供后续 Agent 全流程使用；本章不要求为 MCP 以外的既有模块补录历史事件。

## 非功能需求

- **N1 故障隔离**：日志写入或编码失败不得改变 MCP 连接、工具注册、工具调用或退出的结果。
- **N2 并发安全**：同一进程内来自 MCP 会话、传输和工具调用的并发事件不得产生数据竞争或破坏单条日志记录。
- **N3 可诊断性**：仅查看日志文件即可确认每个 MCP Server 的最终状态：未配置、配置失败、连接失败、初始化失败、发现失败、注册失败或注册成功。
- **N4 最小侵入**：不改变 MCP JSON-RPC 协议内容、工具名称、权限语义、Agent Loop 行为或标准错误的既有用户错误输出。
- **N5 本地性**：日志只输出到当前项目根目录的 `logs/`，不上传、转发或依赖外部日志服务。

## 不做的事

- 不在本章改造 Agent、Provider、权限、TUI 或内置工具的所有现有路径；它们在后续章节按同一日志模块逐步接入。
- 不实现日志上传、集中式收集、远程检索或图形化查看器。
- 不实现日志轮转、压缩、保留策略或删除旧日志。
- 不记录完整请求、响应、工具参数、文件内容或其他可能包含敏感数据的载荷。
- 不因日志文件不可写而终止 MewCode 或禁用 MCP。

## 验收标准

- **AC1（F1、F2）**：在可写项目根目录启动 MewCode 后，`logs/` 下出现一个新的独立日志文件；每行都是可解析的结构化事件，且包含时间、级别、调用位置和消息。
- **AC2（F3、N1、N2）**：日志目录或文件不可写时，MewCode 仍按既有逻辑启动；并发记录 MCP 事件时测试不产生数据竞争，日志中不存在半条或拼接的事件。
- **AC3（F4、N3）**：配置一个成功的 stdio MCP Server 后，日志依次记录其配置、连接、初始化、发现和每个远端工具的注册成功事件，并包含 `filesystem__read_text_file` 这类最终注册名。
- **AC4（F4、N3）**：对配置变量缺失、连接失败、初始化失败、发现失败和注册冲突中的每一种受控场景，日志记录对应 Server 名、阶段和失败状态；其他健康 Server 仍可完成注册。
- **AC5（F5）**：调用一个已注册 MCP 工具后，日志有可关联的开始与完成事件；成功、MCP 工具错误和传输失败均有不同的结果状态。
- **AC6（F6）**：在配置中放入测试 API Key、Authorization 值、环境变量值、工具参数和文件内容后，日志文件不包含这些原始值。
- **AC7（F7、N4、N5）**：MCP 现有单元测试、竞态检查和完整项目测试保持通过；日志模块可被非 MCP 包引用，且日志只写入项目根目录 `logs/`。
