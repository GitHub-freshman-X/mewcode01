# 启动猫头横幅 Plan

## 架构概览

在 TUI 包中定义固定猫头文本，并将其作为 `Model` 初始显示内容的一部分直接写入 viewport。猫头由仅在模型创建时为真的显示状态控制；它不通过系统消息、会话数据或入口诊断 writer 传递。命令入口删除原有横幅输出。

## 核心数据与接口

### `startupCatBanner`

TUI 包级常量，保存用户确认的三行 ASCII 猫头和末尾换行。不接受配置或运行时参数。

### `showStartupCatBanner`

`Model` 的仅内存布尔状态。模型初始化为真；在同一 TUI 进程内创建、清空或恢复会话时保持其初始显示语义，避免将猫头作为新会话内容再次插入。

### `renderStartupCatBanner`

TUI 包内渲染辅助函数，返回无角色标签、无消息背景的纯文本猫头。它只由初始视图内容组装调用。

## 模块设计

### `internal/tui/model.go`

**职责：** 初始化猫头显示状态，并保持会话切换逻辑不把猫头归档或持久化。

### `internal/tui/view.go`

**职责：** 在初始 viewport 内容顶部直接渲染猫头；在既有消息、会话边界、系统消息和任务内容之前组装它，且不调用消息渲染函数。

### `internal/tui/tui_test.go`

**职责：** 验证初始视图含猫头一次、会话和系统消息快照不含猫头，以及会话切换不重复插入。

### `cmd/mewcode/main.go` 与 `cmd/mewcode/main_test.go`

**职责：** 移除 TUI 前横幅写入及其旧测试；保留并扩展入口测试，确认正常路径诊断输出不含猫头。

## 模块交互

```text
命令入口 → 创建 TUI Model → 初始 viewport 组装：猫头 + 既有显示内容 → TUI
                                  │
会话创建 / 清空 / 恢复 ────────────┴→ 仅更新会话显示，不插入或持久化猫头
```

猫头不会经过 `systemMessages`、`Session.DisplaySnapshot`、Provider 请求、日志或入口 `stderr`。

## 文件组织

```text
cmd/mewcode/
├── main.go       — 删除入口横幅输出
└── main_test.go  — 验证入口输出不含横幅
internal/tui/
├── model.go      — 初始化仅显示状态
├── view.go       — 初始 viewport 猫头渲染
└── tui_test.go   — 初始与会话切换显示测试
```

## 技术决策

| 决策点 | 选择 | 理由 |
|---|---|---|
| 渲染位置 | 初始 viewport 内容顶部 | 猫头显示在 TUI 内，并与消息区在同一滚动区域。 |
| 表示方式 | 独立纯文本渲染 | 避免角色标签、消息背景、会话持久化和模型上下文污染。 |
| 会话切换 | 不重新插入 | 横幅属于 TUI 进程级初始界面，不是会话内容。 |
| 输出通道 | 不使用入口 `stderr` | 确保 TUI 外没有横幅。 |
| 测试范围 | TUI 和入口单元测试 | 可无需真实模型服务验证渲染、隔离和入口输出。 |
