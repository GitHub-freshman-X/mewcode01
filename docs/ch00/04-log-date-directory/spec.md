# MewCode 日志日期目录 Spec

## 目标

将每次启动的独立日志文件保存到项目根 `logs/YYYY/MM/DD/`，按本地启动日期分层归档。

## 功能需求

- **F1 日期目录**：日志器按创建时本地日期创建 `logs/<年>/<月>/<日>/`。
- **F2 独立文件**：每次启动继续以时间和 PID 创建独立 `.jsonl` 文件，不覆盖同日既有文件。
- **F3 兼容性**：文件创建失败继续按既有降级逻辑处理；事件格式、调用位置和日志脱敏规则不变。

## 验收标准

- **AC1**：固定本地时间创建记录器后，文件路径为 `logs/2026/08/06/mewcode-*.jsonl`。
- **AC2**：同日期两次创建得到不同文件。
- **AC3**：日志模块竞态测试和全项目测试通过。
