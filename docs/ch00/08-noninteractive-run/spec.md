# MewCode 非交互式单任务执行 Spec

## 背景

MewCode 当前只提供全屏终端交互界面。自动化调用者无法可靠地提交一条任务、等待其结束并以稳定方式读取结果：模拟终端输入会受到界面渲染、权限确认和完成检测的影响。

本章新增一个非交互式单任务入口，使外部程序或脚本能在当前工作目录中执行一条普通 Agent 任务，并获得确定的输出、超时与退出状态。该入口与交互式入口共享既有的 Agent、权限、Hook、Skill、指令和日志能力。

## 目标

- 提供 `mewcode run` 子命令，在当前工作目录中执行一条普通 Agent 任务。
- 支持短任务文本和文件形式的长任务文本。
- 确保命令不会因权限确认或后台任务而无限等待。
- 为人类终端使用和自动化调用分别提供合适且稳定的输出形式。
- 保持当前交互式 TUI 的启动方式与行为不变。

## 功能需求

- **F1 子命令与配置**：提供 `mewcode run`。其配置参数位于 `run` 子命令后；未指定时沿用现有默认配置位置。原有 `mewcode --config <path>` 启动 TUI 的方式保持不变。
- **F2 任务输入**：任务必须且只能通过 `--prompt` 或 `--prompt-file` 之一提供。两者同时提供、均未提供，或去除首尾空白后为空时，命令应在启动 Agent 前报错。
- **F3 执行范围**：每次调用仅执行一条普通动作任务，并以调用进程的当前工作目录作为工作区。第一版不公开计划、执行计划或上下文压缩等其他任务模式。
- **F4 初始化一致性**：非交互式入口应加载并应用与交互式入口相同的配置、项目与用户指令、记忆索引、Skill、Hook、MCP 工具、权限规则和安全日志。
- **F5 非交互权限**：已被规则或权限模式直接允许的工具调用可以执行；任何原本需要人工确认的调用必须自动以拒绝结果返回给 Agent，且命令不得等待输入。
- **F6 子 Agent 边界**：前台子 Agent 可正常完成；请求以后台方式运行的子 Agent 必须被拒绝，以保证顶层调用结束时不遗留未完成工作。
- **F7 生命周期与超时**：命令默认最多运行 30 分钟，并允许用户显式关闭总超时。超时或收到中断信号时，应取消 Agent 并以可区分的终态结束。
- **F8 文本输出**：默认模式将 Agent 文本增量实时写至标准输出；诊断和错误信息写至标准错误。成功完成后，标准输出即为最终 Agent 文本。
- **F9 JSON 输出**：`--json` 模式不得在标准输出混入流式文本或诊断；任务结束时应输出一个 JSON 结果，其中至少包含状态、停止原因、错误信息（如有）、最终文本、耗时、迭代数和 Token 用量。
- **F10 退出状态**：退出码必须稳定区分：正常完成、启动/参数/运行失败、取消、总超时，以及因迭代上限或未知工具上限而安全停止。
- **F11 临时状态**：非交互式调用使用临时会话，不保存可恢复会话，也不触发长期记忆提取或写入；仍保留既有只含安全元数据的运行日志。

## 非功能需求

- **N1 非阻塞性**：在没有连接交互式 UI 的情况下，权限确认、后台子 Agent 请求、超时和中断均不得使进程无期限阻塞。
- **N2 自动化稳定性**：JSON 输出在一次调用中必须是单个可解析文档；不同终态的退出码语义稳定，便于脚本处理。
- **N3 安全性**：不得因非交互模式扩大现有权限；日志、标准错误和 JSON 结果不得泄露密钥、原始 prompt、工具结果正文或请求头。
- **N4 兼容性**：既有 TUI 参数、默认配置、交互式权限确认与会话行为保持不变。
- **N5 可测试性**：参数校验、超时、权限自动拒绝、输出分流、退出码和临时状态均应可在不调用真实模型服务的自动化测试中验证。

## 不做的事

- 不实现 SWE-bench-Live 下载、容器编排、测试执行、判分、批量调度或重试。
- 不实现多任务队列、并发运行、后台持续服务或远程控制接口。
- 不通过该入口公开 `plan`、`do`、`compact` 或会话管理模式。
- 不支持从标准输入读取任务文本。
- 不新增工作目录参数；调用者应在目标工作目录中执行命令。
- 不保存或恢复本次调用的会话，不写入长期记忆。
- 不改变当前 TUI 的功能、参数语法或默认交互权限行为。

## 验收标准

- **AC1（F1）**：`mewcode run --config <path> ...` 使用指定配置启动；已有 `mewcode --config <path>` 仍启动 TUI。
- **AC2（F2）**：仅提供非空 `--prompt` 或非空 `--prompt-file` 时可启动任务；缺失、同时指定或空内容均在模型请求前失败。
- **AC3（F3、F4）**：一次 `run` 调用只启动一个普通动作任务，工作区为当前目录，并加载现有扩展与配置来源。
- **AC4（F5）**：遇到需要确认的工具调用时，Agent 收到拒绝结果且进程不阻塞；已允许的调用可继续执行。
- **AC5（F6）**：前台子 Agent 可完成；后台子 Agent 请求被拒绝，且顶层命令结束后不存在由该调用遗留的后台工作。
- **AC6（F7）**：默认总超时为 30 分钟；显式关闭超时后不创建总超时限制；超时和中断均取消任务并产生各自约定的终态。
- **AC7（F8）**：默认模式中，文本增量实时出现在标准输出，诊断不混入标准输出。
- **AC8（F9）**：`--json` 模式的标准输出可作为单个 JSON 文档解析，且含状态、停止原因、错误、最终文本、耗时、迭代数和 Token 用量。
- **AC9（F10）**：正常完成、普通失败、取消、超时和安全停止分别返回约定的退出码。
- **AC10（F11）**：调用后不存在可恢复会话或新增长期记忆；安全元数据日志仍可用于诊断。
- **AC11（N4、N5）**：既有 TUI 启动回归测试及非交互入口的离线自动化测试均通过，无需真实模型服务。
