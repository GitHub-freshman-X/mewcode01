# MewCode Git Worktree 文件系统隔离 Checklist

## 生命周期与安全

- [x] 合法名称可创建独立目录、分支与正确 HEAD；重复创建可快速恢复。（验证：临时 Git 仓库测试）
- [x] 空名、超长、`.`、`..`、空路径段、遍历和非法字符均被拒绝，且无 Git/文件写入。（验证：参数化单元测试）
- [x] Git 调用不会等待凭据或终端输入。（验证：Git 执行器环境测试）
- [x] 正常退出清除 Session；恢复模式仅恢复仍有效的 Session。（验证：会话持久化测试）

## 环境与显式 cwd

- [x] 配置文件、hooks、依赖链接和被忽略运行文件按配置尽力初始化；某项失败不破坏 Worktree。（验证：临时项目集成测试）
- [x] 进入 Worktree 后进程 cwd 不变，文件工具和命令工具均在 Worktree 中执行。（验证：比较 `os.Getwd`、文件内容与命令输出）
- [x] 主工作区和不同 Worktree 的同名文件及缓存互不混淆。（验证：多 Workspace 集成测试）

## 保护与清理

- [x] 干净目录可删除；未提交修改或新提交存在时，未确认丢弃则拒绝删除。（验证：Git 状态场景测试）
- [x] 隔离任务完成后，干净临时目录自动删除；有改动目录保留并回传路径、分支。（验证：SubAgent 集成测试）
- [x] 过期清理只删除符合临时模式、未使用、过期且无未提交、新增或未推送提交的目录。（验证：三层过滤测试）
- [x] 任一安全检查出错时保留目录并写安全日志。（验证：注入 Git/文件错误）

## SubAgent 集成

- [x] Fork 无论参数为何均在启动时创建唯一 Worktree，保留历史继承、强制后台与通知语义。（验证：Runtime 测试）
- [x] 定义式 Agent 仅在 frontmatter 或调用参数声明 `worktree` 时隔离。（验证：定义加载与 cwd 测试）
- [x] 未隔离前台定义式 Agent 仍在主工作区运行，且不能在执行中转后台。（验证：ESC 与超时接管测试）
- [x] 隔离提示要求重新读取本地文件并转换主目录绝对路径。（验证：捕获子 Agent 首条任务文本）

## 命令、文档与回归

- [x] `/worktree create|list|enter|exit|remove` 输出路径、分支、状态或安全拒绝原因。（验证：命令测试）
- [x] 示例配置、README、章节索引与实际字段、命令保持一致。（验证：文档审阅）
- [x] 生命周期日志只含阶段、状态、计数、类型、耗时、大小、Token 等安全元数据。（验证：日志断言）
- [x] 项目格式化、全部单元测试与手工端到端场景通过。（验证：对应命令与实际输出）

## 端到端场景

- [x] Fork 编辑文件 → 主工作区文件不变 → 子任务完成后 Worktree 保留、主 Agent 获得路径与分支。（验证：真实临时仓库）
- [x] Fork 仅读取与分析 → 任务完成 → 临时 Worktree 自动删除。（验证：检查目录不存在）
- [x] 手动创建并进入 Worktree → 编辑文件 → 未确认删除被拒绝 → 确认丢弃后删除成功。（验证：命令流程）
