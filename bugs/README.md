# Bug 记录

该目录用于记录 MewCode 开发和实际使用中确认存在、具有复现或诊断价值的问题。

## 目录约定

按日期建立子目录，每个问题单独记录：

```text
bugs/
├── README.md
└── YYYY-MM-DD/
    ├── README.md
    ├── 001-short-bug-name.md
    └── 002-another-bug.md
```

文件序号只要求在当天目录内递增。每份记录应尽量包含：

- 状态和影响范围
- 用户可见现象
- 复现条件
- 根因
- 修复方案
- 验证方式
- 后续工作
