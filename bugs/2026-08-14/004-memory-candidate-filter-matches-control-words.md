# 记忆候选筛选将控制语句误判为长期记忆

- 状态：待处理
- 发现日期：2026-08-14
- 影响范围：`internal/memory/service.go`

## 现象

最新手工测试中，普通 `/plan` 请求“制定一个只读计划……不要执行工具”在 10:37:22 触发了 `memory extraction completed`，模式为 `plan`。

## 根因

候选筛选只要发现“不要”“规则”“以后”等孤立词就触发。控制语句“不要调用工具”“不要执行工具”不包含可持久化的用户偏好或项目知识，却命中了“不要”。

## 建议修复

改为识别完整的明确记忆表达，例如“请记住”“我的偏好是”“项目长期知识是”，而不是匹配单个高频控制词；为普通任务、`/plan` 控制语句和工具约束增加负向回归测试。
