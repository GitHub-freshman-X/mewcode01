# 活跃任务与会话历史重复渲染工具输出

- 状态：已修复，定向自动化验证通过
- 发现日期：2026-08-18
- 影响范围：包含工具调用的活跃 Agent 任务的 TUI 展示。

## 现象

同一工具调用和结果在任务仍活跃时出现两次，随后输出与系统消息的时间顺序难以辨识。

## 根因

Runner 每一轮工具执行后立即把该轮写入 `Session.DisplaySnapshot()`；TUI 同时渲染整个会话历史和 `taskView` 中累计的 `toolCalls`、`toolResult`，但没有按调用 ID 排除已写入历史的项目。

## 后续工作

在渲染活跃任务视图时，以调用 ID 过滤已经出现在会话展示历史中的工具调用和结果，并用回归测试断言同一调用只显示一次。
