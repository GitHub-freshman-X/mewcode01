# 启动猫头错误输出在 TUI 外部

- 状态：已修复，自动化验证通过
- 发现日期：2026-08-21
- 影响范围：启动猫头横幅功能。

## 现象

启动猫头被写入终端标准错误输出，显示在进入 TUI 之前，而非 TUI 内部。

## 根因

入口层在调用 TUI 前直接向诊断输出 writer 写入猫头；该输出不属于 TUI viewport 的渲染内容。

## 修复方案

移除入口层输出，改由 TUI 初始化时将猫头作为独立的视觉元素渲染在消息区域；不创建系统消息，不写入会话、模型上下文或日志。

## 验证方式

2026-08-21：`go test ./cmd/mewcode ./internal/tui -run 'Test.*(Banner|Clear|View)' -count=1`、`go test ./... -count=1` 和 `go build ./cmd/mewcode` 均通过。入口测试确认诊断输出不含猫头；TUI 测试确认初始渲染一次且创建、清空、恢复会话后不重复。手工 TUI 验证因未提供有效 Provider 配置尚未执行。
